# crexi_us_building_sales
Crexi-US is a website where building, spaces were listed for sales and auction.

Using thi scraper we can either get complete data points available in the crexi-us or we can get only particular area building related information.

This scrapper will be helpful,
1. As we see it has a auction biding. This is help you prepare in advance on how much the particular building / space can fetch.
2. We can relate the information about buildings in particular area sold and value other building/spaceproperly.
3. Help's in analysis purpose and get more relevant and detaild information on the building/space.
